Sekcja 1 · Problem

Jaki problem rozwiązuje pakiet?

Wybór miasta do zamieszkania jest decyzją wielowymiarową. Żadne pojedyncze kryterium nie daje pełnego obrazu sytuacji, dlatego potrzebujemy narzędzia uwzględniającego wszystkie wymiary jednocześnie.

Problem

Porównywanie miast na podstawie jednego wskaźnika prowadzi do błędnych wniosków. Alternatywy różnią się na wielu wymiarach jednocześnie, a preferencje decydenta są z natury niepewne.

Użytkownik

Student szukający pracy, rodzina planująca przeprowadzkę, emeryt wybierający miejsce do życia — każdy ma inne priorytety, które pakiet modeluje osobno za pomocą predefiniowanych profili.

Wynik

Ranking miast z meta-rankingiem konsensusu agregującym trzy metody MCDA. Wynik uwzględnia niepewność danych poprzez logikę rozmytą i mechanizm progów akceptowalności.

Sekcja 3 · Metody

Rozmywanie danych i wagi

Trójkątne liczby rozmyte

Pojedyncza ocena nie jest traktowana jako idealnie dokładna. Pakiet tworzy trójkę (l, m, u): dolną, środkową i górną wartość, modelując naturalną niepewność danych źródłowych.

Dla wartości x po skalowaniu do skali Saaty'ego (1–9) pakiet tworzy:

TFN = (max(1, x−1), x, min(9, x+1))

Defuzzyfikacja do wyniku ostrego przebiega według wzoru:

wynik = (l + 4m + u) / 6
Wagi kryteriów — profil studenta

Sekcja 5 · Odtworzenie

Jak odtworzyć wyniki?

Pełna analiza jest odtwarzalna z kodu. Poniżej kompletna ścieżka analityczna od instalacji do eksportu wyników.

# 1. Instalacja pakietu z GitHub devtools::install_github("OlaStepak/CityOptimaR") library(CityOptimaR) # 2. Wczytanie danych data("city_data") # 3. Analiza dla wybranego profilu wynik <- analyze_cities( city_data, profile = "student" ) # 4. Podgląd rankingu wynik$ranking # 5. Wykres bąbelkowy VIKOR plot(wynik$vikor) # 6. Tabela APA gotowa do Worda tabela <- tabela_apa(wynik$topsis) zapisz_tabele(tabela, "wyniki.docx") # 7. Pozostałe profile wynik_family <- analyze_cities(city_data, profile = "family") wynik_retiree <- analyze_cities(city_data, profile = "retiree")
1

Zainstaluj pakiet

Pakiet dostępny na GitHub. Wymagane: R ≥ 4.0 oraz pakiet devtools.

2

Wybierz profil

Dostępne profile: student, family, retiree. Możliwe jest też podanie własnych wag i progów.

3

Uruchom analizę

Funkcja analyze_cities() wykonuje pełny przepływ: fuzzyfikacja, wagi, TOPSIS, VIKOR, WASPAS i meta-ranking.

4

Eksportuj wyniki

Tabele w formacie APA gotowe do Worda. Wykres bąbelkowy generowany przez plot().
